Common questions.

Will my members actually use it?

Adoption builds week over week as members start noticing the QR codes on equipment, not instantly. We push for high utilization in week one, then see it climb steadily from there as scanning becomes routine.

Do members need to download an app?

No. ScanSet runs as a web app right in the browser, no download, no app store. Members can add it to their home screen for an app-like feel if they want, and it's always current since there's no manual update step. Every member on your gym is on the latest version automatically.

What if a QR code gets damaged, or I add new equipment?

Print a new one anytime from the owner portal. Replace a damaged sticker, update a machine, or add a code for new equipment, all self-serve.

Is there a contract?

Plans run on a 3-month minimum, long enough for adoption to build before you judge results. After that, it's month to month.
